# Dependencies and research references

- **Dear ImGui**, official repository, MIT license: [ocornut/imgui](https://github.com/ocornut/imgui). The build pins v1.92.5-docking commit `af84778eeaab75bee0b54420f3157cf3ee00618f`. Its license remains in the fetched source tree.
- **Ghidra**, official repository: [NationalSecurityAgency/ghidra](https://github.com/NationalSecurityAgency/ghidra). Used locally to analyze the user's executable and overlay bytes. Generated decompiler output is a research artifact and is not compiled into the native engine.
- **Spyro2x2**: [Spyromain/Spyro2x2](https://github.com/Spyromain/Spyro2x2), inspected at commit `2203b9d0a3aa7b0d7f2f77258c89006eb6c229c9`. USA symbol candidates come from `projects/rr/symbols.ld`. Its `Sp2.h` address comments use the PAL map and must not be applied to this executable.
- **Spyro-Scope**: [FranklyGD/Spyro-Scope](https://github.com/FranklyGD/Spyro-Scope), inspected at commit `e82b8f86b857ce6abe5ace108f14eaf6bd195cca`. GPL-3.0 reference used for format leads. The C++ parsers are independently written and checked against retail bytes and executable analysis; the reference implementation is not built or redistributed in this project.
- **PSX-SPX CD-ROM format documentation**: [CDROM File Formats](https://psx-spx.consoledev.net/cdromfileformats/), used for disc container research.
- **PSX-SPX graphics documentation**: [GPU commands and blending](https://psx-spx.consoledev.net/graphicsprocessingunitgpu/) and [GTE registers and instructions](https://psx-spx.consoledev.net/geometrytransformationenginegte/), used to interpret the retail shiny-object packet path, signed interpolation gain and additive blend state.
- **Audio format and playback references**: [PSX-SPX XA](https://psx-spx.consoledev.net/cdromformat/) and [SPU](https://psx-spx.consoledev.net/soundprocessingunitspu/); [DuckStation SPU arithmetic](https://github.com/stenzek/duckstation/blob/master/src/core/spu.cpp); [FFmpeg ADPCM decoder](https://github.com/FFmpeg/FFmpeg/blob/n8.0/libavcodec/adpcm.c) for independent XA comparisons and investigation of SPU rounding differences; [Microsoft XAudio2](https://learn.microsoft.com/en-us/windows/win32/xaudio2/how-to--initialize-xaudio2) for Windows playback. These external decoders are research references, not engine dependencies.

Local research clones are under ignored `research/local/`. The retail binary, archives, textures, models and animation data are loaded from the user's game copy and are not engine distribution assets.
